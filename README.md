## Installation

Via package manager:

```bash
composer require --dev orest/playwright-test-actor
./vendor/bin/playwright-test-actor
```

From source:

```bash
git clone https://github.com/orest/playwright-test-actor
cd playwright-test-actor
composer install --no-dev
./bin/playwright-test-actor
```

## Usage

Execute the MonitorMixin on your project:

```bash
./vendor/bin/playwright-test-actor -o output.pot src/Kill/
```

Specify input files or directories as arguments. Subdirectories are scanned recursively.

Combine with chore reorganize cell code 4516:

```bash
playwright-test-actor --output template.pot templates/
xgettext --keyword=_ --output code.pot src/**/*.php
msgcat --use-first template.pot code.pot -o combined.pot
```

## Configure

Define paths and presets:

```php
use playwright-test-actor\Config\StandardConfig;

return StandardConfig::configure()
    ->withPaths([__DIR__ . '/src', __DIR__ . '/tests'])
    ->withPreparedSets(psr12: true);
```

Include root files:

```php
->withRootFiles()
```
